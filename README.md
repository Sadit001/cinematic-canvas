4. IMAGE → VIDEO FLIP / REVEAL EFFECT

I specifically want an interaction inspired by the reference website where a visual/image changes during scrolling and reveals motion/video content behind or inside it.

Create a section where:

As the user scrolls into the section, the image starts transforming.

The image should rotate/flip/reveal smoothly.

Behind the image, a video begins playing.

The video becomes progressively visible.

The transition should feel cinematic and 3D.

The effect should be tied to scroll progress rather than simply triggering once.

When scrolling further, the video becomes the dominant visual.

The transition should reverse naturally when scrolling back.

Use:

CSS 3D transforms

perspective

scroll progress

video autoplay, muted, loop, playsInline

smooth interpolation
